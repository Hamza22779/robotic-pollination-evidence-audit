Overview

This repository contains the companion data files supporting the review article:

The Unmeasured Middle Between Robotic Pollination Action and Biological Receipt

The repository preserves the structured evidence base used for the review and provides transparent access to the publication classification, programme-family matrices, direct-report extraction matrices, cohort-level extraction records, citation-chasing records, source-certainty assessments, experiment-level descriptors and coding, biological-attribution audit, and manuscript-reference crosswalks.

These files were moved out of the journal-facing Supplementary Information (SI) to keep the submitted supplementary document compact. No underlying evidence was deleted by that relocation.

Repository scope

The companion dataset covers the review's evidence-audit structure at several linked levels, including:

the complete 344-publication classification crosswalk;

22 programme-family matrices;

30 direct empirical report records;

50 cohort-extraction rows from 10 reports;

citation-chase additions and closed routes;

per-report source-certainty and provenance information;

independent experiment-level descriptors and evidence coding;

biological-attribution auditing;

main-manuscript reference-role mapping; and

the direct-report LIT-ID-to-citation crosswalk.

Relationship to the manuscript and Supplementary Information

The repository is intended to function as the machine-readable companion to the review article and its journal-facing Supplementary Information.

The journal SI can therefore remain concise while this repository provides the fuller data tables and archival materials needed for transparent inspection and reproducibility.

The data-file identifiers D01–D13 should remain stable so that citations from the manuscript, Supplementary Information, data-availability statement, or future archived release can point to the same resources unambiguously.

Recommended use

Users of this repository should cite the associated review article together with the archived repository release once the article and permanent repository DOI are available.

When analysing the CSV files, users should preserve the distinctions among publication-level, programme-family-level, direct-report-level, cohort-level, and independent-experiment-level records rather than combining their denominators.

Versioning and archival release

For the manuscript-linked public release, the recommended workflow is:

maintain the working repository on GitHub;

create a tagged release corresponding to the submitted or accepted manuscript version;

archive that release through Zenodo or another DOI-issuing repository; and

cite the permanent DOI in the manuscript's Data Availability statement.

A release tag such as v1.0.0 can be used for the manuscript-associated frozen dataset.

Data and copyright note
